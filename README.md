# MediStock — Pharmacy Inventory

A lightweight pharmacy stock management dashboard built with Angular 11. It includes a responsive inventory view, stock alerts, search and category filters, and medicine add/edit/remove workflows. Inventory changes are saved in the browser using localStorage.

## Getting started

```bash
npm install
npm start
```

The development server opens at `http://localhost:4200`. Create a production build with `npm run build`.

## Notes

The app starts with sample inventory for demonstration. Data remains in the current browser and device; connect an API and authentication service to use it with a shared pharmacy database.
